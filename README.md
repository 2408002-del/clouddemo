# Hello Cloud

This is a simple static website created for a cloud deployment assignment.

## Project Overview
- Built with HTML and CSS
- Responsive design for desktop and mobile screens
- Ready to deploy on Vercel or Render

## Files
- `index.html` — main page structure
- `styles.css` — page styling and responsive layout

## Deployment Steps
1. Push this project to your GitHub repository.
2. Open [Vercel](https://vercel.com).
3. Import the GitHub repository.
4. Click **Deploy**.
5. Wait for the build to complete and get your live site URL.

## Example Deployment URL
`https://hello-cloud.vercel.app`

## Notes
This static site can also be hosted on Render using the same GitHub repository.
